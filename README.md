# Saeed Damra — Portfolio

Personal portfolio for a Digital Forensics & Incident Response analyst.
Static site: plain HTML, CSS and vanilla JavaScript. No build step, no dependencies.

1. **Certifications** — placeholder cards. Replace the name and issuer on each,
   delete any you don't need. `data-status="active"` shows a green dot,
   `data-status="progress"` shows an amber one.
2. **Projects** — placeholder cards with a hatched "pending" thumbnail.
   Swap in a real image and description when you have one.
3. **Contact form** — set `data-endpoint` on `<form id="contact-form">` to a
   Formspree (or any POST) URL to receive messages directly.
   Leave it empty and the form falls back to opening the visitor's mail client
   with the message pre-filled, so nothing is silently dropped.
