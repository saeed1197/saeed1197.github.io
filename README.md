# Saeed Damra — Portfolio

Personal portfolio for a Digital Forensics & Incident Response analyst.
Static site: plain HTML, CSS and vanilla JavaScript.

Live at [saeed1197.github.io](https://saeed1197.github.io).

## Structure

- `index.html` — all page sections: Home, About, Skills, Experience, Certifications, Projects, Contact.
- `assets/style.css`, `assets/newcss.css` — styling.
- `assets/main.js`, `assets/ptj.js` — theme toggle, scroll reveal, typed text, contact form handling.
- `assets/swiper-bundle.min.*` — third-party carousel library.
- `assets/img/` — project logos and profile photo.
- `assets/MyCV.pdf` — downloadable CV.
